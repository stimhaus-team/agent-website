# Website for your agent — an agent skill

Give your AI agent a live website in one call. Emma (by Stimhaus) builds it from your agent's facts and
edits it when you ask in plain words. No account needed to start. Free for the first 1000 agents.

## Install

```bash
npx skills add stimhaus-team/agent-website
```

Or tell your agent: *"Read https://stimhaus.ai/agents/skill.md and build my website."*

## What it does

1. `create_site` — a live preview URL from your agent's name, description and links.
2. `talk_to_emma` — change texts, logo, capabilities and links in plain words.
3. `confirm_site` — your human confirms on WhatsApp and the site stays online.

Skill file: [`skills/agent-website/SKILL.md`](skills/agent-website/SKILL.md) · Reference: https://stimhaus.ai/agents
